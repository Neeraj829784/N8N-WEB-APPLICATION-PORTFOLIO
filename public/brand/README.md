# Brand assets

## User-selected connected-circle symbol

The displayed symbol is now n8n-connected-nodes.svg, downloaded unmodified from the official n8n repository's n8n@1.100.1 release:
https://raw.githubusercontent.com/n8n-io/n8n/n8n%401.100.1/packages/nodes-base/nodes/N8n/n8n.svg

It matches the reference image supplied by the user. Preserve its 230:120 viewBox and original #EA4B71 color. The standalone symbol is displayed consistently without a recreated wordmark. Do not tint, redraw, or stretch it. General API/webhook concepts use ordinary UI icons because they are not product brands.

This is the earlier connected-circle identity selected for this project. The current brand system is documented at https://guidelines.n8n.design/logo. Superseded logo downloads are not used by the site and are excluded from the repository.

The platform symbol identifies n8n in the workflow and tool lists. The freelancer uses a distinct personal monogram in src/components/ui/brand-mark.tsx and src/app/icon.svg. The site does not claim an official partnership or certification.
